    面片轨迹

    选择原始纸格与正/反面后，系统从第 0 步到末步生成时间线： 每一步该片所在格位、叠层中的层序、所选面朝上/朝下与正立/倒置。 点击任一节点即联动上方回放定位到该步并高亮该片；首个非法步骤会中断时间线并标明原因。

    校样批注

    在画布点击任一格位（可在弹层中选择该叠中的原始纸格与正/反面）添加批注： 记录添加时的回放步、严重级别与正文。批注始终绑定原始面片身份， 切换回放步、截断或重排折叠后标记仍定位到正确格位；勾选“仅未解决”只看待办项。

        双面印刷版预览

        全部折叠合法并收成单叠后，按当前纸格标注并排生成正面版 / 背面版： 背面纸格按所选翻转边镜像，格内页码再按面片朝向旋转，打印后沿所选边翻面、 按既有步骤折叠时，阅读顺序与当前回放一致。

        书帖爬移补偿

        全部折叠合法并收成单叠后，以最外叶为第 0 层，按 补偿量 = 纸厚 × 外侧叶数 把各叶内容沿前口 → 书脊方向内移， 并换算为原始纸格正/反面的带符号横向偏移。偏移绝对值超过可用出血的面会标红， 此时不可应用。
